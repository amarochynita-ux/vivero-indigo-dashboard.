# 🌿 Dashboard de Gestión Integral - Vivero Indigo

## 📌 Descripción del Proyecto

Este proyecto consiste en el desarrollo de una aplicación web interactiva para centralizar la gestión del inventario y las ventas de un vivero, permitiendo visualizar indicadores clave y facilitar el seguimiento de la información mediante dashboards interactivos.

El objetivo fue mejorar la organización de los datos y proporcionar una herramienta que apoye la toma de decisiones relacionadas con el control del inventario y el desempeño comercial.

---

## 🎯 Objetivo

Desarrollar un dashboard interactivo que facilite la administración del inventario, el seguimiento de ventas y la visualización de indicadores relevantes para la operación del vivero.

---

## 📂 Datos utilizados

El proyecto integra más de 500 registros relacionados con:

- Inventario de plantas.
- Ventas.
- Estado del stock.
- Indicadores financieros.
- Información operativa.

---

## 🔍 Actividades realizadas

- Limpieza y preparación de los datos.
- Desarrollo de una aplicación web con Streamlit.
- Diseño de dashboards interactivos.
- Automatización de alertas para productos con stock crítico.
- Visualización de indicadores financieros y comerciales.
- Implementación de un sistema de priorización de tareas para apoyar la gestión operativa.

---

## 📊 Resultados

El dashboard permitió centralizar la información del inventario y las ventas en una única plataforma, facilitando el seguimiento del stock y la consulta de indicadores mediante visualizaciones interactivas.

---

## 💼 Aplicación al negocio

La solución desarrollada puede contribuir a:

- Mejorar el control del inventario.
- Facilitar la identificación de productos con bajo stock.
- Dar seguimiento al comportamiento de las ventas.
- Apoyar la planificación de compras.
- Optimizar la toma de decisiones mediante indicadores visuales.

> **Nota:** Este proyecto fue desarrollado como parte de un portafolio profesional y muestra una posible aplicación de herramientas de análisis de datos para la gestión de inventarios.
