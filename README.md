# 🌿 Vivero la Indigo - Dashboard de Gestión

Este proyecto es una aplicación web interactiva desarrollada en **Python** diseñada para optimizar la administración operativa y financiera de un vivero.

## 🚀 Funcionalidades Clave
- **📊 Resumen Ejecutivo:** Visualización de valor de inventario y stock total.
- **💧 Alertas de Riego:** Semáforo inteligente para el cuidado de las plantas.
- **📈 Inteligencia de Ventas:** Gráficas interactivas con tendencias por mes y día.
- **🌦️ Guía de Temporada:** Consejos dinámicos de cuidado según el mes actual.

## 🛠️ Tecnologías
Python, Streamlit, Pandas y Plotly.
